## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `entry.png` to the output directory, which is all the program has to do. The entry is the image itself. The image is a 1024x1024 PNG newspaper front page, drawn as HTML and rendered to pixels, so every headline is real text and nothing is garbled.
